Build a clean watchlist from Amplify ETF constituents.

This static browser app follows the single-file approach from daggerok/iShares, but reads a generated ./api/data.json file built from Amplify's public ETF catalog and holdings data. Choose the funds you care about, filter out cash, Treasuries, money-market rows, and option strings by preset, then export symbols in CSV or TXT format.

How to use

1. Search or filter the ETF catalog and select one or more funds.

2. Click Load selected holdings to read the selected funds from the local static data API.

3. Adjust the symbol preset, then copy a deduped watchlist or export the full table.

ETF catalog

Catalog and holdings are read from ./api/data.json, generated by the bun update script or the manual GitHub Actions workflow.

Watchlist controls

Selections persist locally in this browser. Holdings are read from the static data API on demand.

ℹ️
Default filtering removes cash, money-market funds, Treasury/CUSIP-like identifiers, option contracts, and derivative/futures strings. Use Raw holdings when you want to audit every line item exactly as Amplify publishes it.
